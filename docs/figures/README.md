# 문서 그림 원본과 재생성

이 폴더의 SVG는 외부 폰트·스크립트·네트워크 의존성이 없는 설명 그림이다. Markdown 미리보기에서 이미지를 직접 표시한다. 한글 글꼴은 `Noto Sans CJK KR`, `Noto Sans KR`, 시스템 sans-serif 순서로 사용한다. 크게 보려면 SVG 파일을 연다. `title`, `desc`, 문서의 대체 텍스트와 본문 설명도 함께 제공한다.

- `limit-scenes.json`: A01~L10 전체 142개 사례의 상황 → 판단·변화 → 결과를 직접 작성한 설명 원본. 현재 상태·제안 문구는 `oms_client/replay/limit_case_matrix.json`과 결합한다.
- `overview-scenes.json`: 전략·재생·대기열·헤지·회계·운영 개념도 36개의 원본과 설명.
- `document-bindings.json`: 각 개념도를 넣은 문서·절의 위치. 본문 변경 시 설명과 위치도 함께 갱신한다.
- `a01.svg` 등: 사례별 그림. 수정용 Mermaid는 `docs/illustrated/limit-*.ko.md`에서 접어서 제공한다.
- 개념도 `.svg`와 `.mmd`: 바로 보는 그림과 대응하는 Mermaid 흐름도 원본.

저장소 루트에서 다음을 실행한다.

```bash
/home/minsung1/dev/.venv/bin/python tools/render_docs_diagrams.py
/home/minsung1/dev/.venv/bin/python tools/render_docs_diagrams.py --check
```

첫 명령은 SVG·Mermaid·분류별 사례 문서를 재생성한다. 기존 제안서 본문의 그림 위치·설명은 자동 덮어쓰지 않는다. `--check`는 생성물 일치, XML 형식, 사례 ID 1:1 대응, 두 사례표의 142개 그림 링크, 개념도 배치와 설명을 검사한다. 런타임 코드나 사례 지원 상태는 변경하지 않는다.

그림은 복잡한 분기 전체를 하나에 우겨 넣는 대신 **특정 조건에서의 사건 순서**를 세 칸으로 표현한다. 분기별 비교는 별도 사례와 본문 행렬을 함께 읽는다. 작은 화면에서는 이미지를 확대할 수 있고, 이미지가 표시되지 않아도 그림 아래의 같은 내용을 읽을 수 있다.

현재 실행 범위와 제안의 차이를 표시한다. 보라색·점선은 사례 카탈로그의 미지원 설계, 황색은 부분 지원, 청색은 모형 가정, 녹색은 실행·차단 연결이다. 색만으로 구분하지 않도록 상태 문구를 항상 적는다. 개념도는 상단에 적용 범위를 적고 본문 설명에서도 미연결 영역을 명시한다.

대기열 경계 사례 C06~C10·D01~D03은 같은 축척의 처리 전·후 잔량 막대를 함께 제공한다. 회색은 외부 물량, 청색·녹색은 내 주문이며 수량·주문 이름을 글자로도 표시한다.
