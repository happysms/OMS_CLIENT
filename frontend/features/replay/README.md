# 모의투자 과거 데이터 화면

별도 시뮬레이션 탭 없이 `모의투자` 안에서 과거 데이터/실시간 시세를 선택합니다. `shell/workspace.js`의 `initUnifiedPaper`가 화면과 조회 수명을 관리합니다. 방식 전환은 서버 재생을 중단하거나 가상계좌를 초기화하지 않습니다. 이전 `#replay` 링크는 `#paper`, `#manual` 링크는 `#paper-live`로 연결합니다. 전략의 실행 선택은 과거 데이터 방식으로 진입합니다.

## 보고 통화

손익 표시 통화는 KRW/USDT 중 선택하고 브라우저에 보관한다. USDT의 과거 원가·손익은 서버 보고서에서 선택하며, 체결 표 캐시에 통화를 포함한다. 체결 당시 이론가는 고정 보고서의 환율만 적용한다. 별도 원본 호가·틱·주문 입력의 통화는 바꾸지 않는다. 환율과 과거 원가 없는 값은 비워 둔다. 자세한 UI·계산 계약은 [통화 보고 문서](../../../docs/pnl_currency.ko.md)를 따른다.
