# 실시간 수동매매 화면

기본 배포는 원격 실행 방식이다. `manual_market_view`로 공개 시세 화면만 활성화하고 `manual_spot_orders=false`이면 키 입력·개인 조회·주문을 비활성화한다. 원격 소켓 제어는 [정의서](../../../docs/remote_execution_socket.ko.md)에 따라 후속 연결한다. 아래 직접 주문 동작은 명시적으로 활성화한 호환 모드에 한한다.

`controller.js`는 공개 현물 5호가·틱, 마스킹된 키 관리, 명시적인 실제 지정가 주문·취소·상태 조회를 표시한다. 초기화할 때 네트워크 요청을 하지 않는다. 활성 탭에서만 서버 스냅샷을 1초마다 읽으며 주문 상태를 공개 체결로 추정하지 않는다.

주문 전송은 매번 실제 계좌 확인이 필요하다. 응답을 잃은 요청 ID는 유지하고 같은 내용으로만 재시도한다. 서버가 전송 전 실패를 명시한 경우에만 입력을 고쳐 새 의도를 만들 수 있다. 키 원문은 로컬 저장소에 넣지 않고 등록 시도 후 입력란을 비운다.

자세한 범위·상태 전이·API·보관·후속 질문은 [서버 모듈 문서](../../../oms_client/manual_trading/README.md)를 참고한다. 회귀 검증은 `tests/frontend/manual_trading.mjs`에 있다.
