# 데이터 파일 탐색기

`controller.js`는 왼쪽 폴더 트리와 선택 파일의 메타데이터를 표시합니다. 폴더를 펼칠 때만 `/api/data/files`를 호출하고 파일 선택 시 `/api/data/files/info`를 호출합니다. 트리 탐색·검색·페이지·상세 정보 요청을 별도로 관리하여 이전 응답이 새 선택을 덮지 않게 합니다.

실제 디렉터리 접근과 파일 형식 검증은 서버의 `market_data/file_browser.py`가 담당합니다. 파일을 클릭하면 메타데이터를 확인한 뒤 `shell/workspace.js`의 `onOpenQuery`를 통해 데이터 탭에서 바로 조회합니다. 호가·체결 틱·분봉·펀딩비율의 종류·거래소·종목과 정확한 파일 기간을 적용하며, 폴더 클릭은 기존처럼 목록만 펼칩니다. 체결 틱은 일반·압축 Parquet를 모두 지원하고 기본 조회 간격은 1초입니다. 이 모듈은 가격·펀딩을 계산하지 않습니다.

선택을 바꾸거나 목록을 새로고침하면 이전 메타데이터 요청과 구간 열기의 `AbortSignal`을 취소합니다. `onOpenQuery(query, {signal, isCurrent})`는 유효한 선택인지 확인한 뒤 조건과 결과를 적용해야 합니다. 빠르게 여러 파일을 선택해도 이전 선택이 나중에 데이터 탭을 덮지 않도록 합니다. 실패한 구간은 상세 정보의 다시 조회 버튼으로 재시도할 수 있습니다.

같은 모듈의 `initStorage`는 모든 탭 위의 서버 저장 공간·자동 정리 패널을 담당합니다. 디스크별 용량, 1~3650일 보관 설정, 기본/전용 저장소 선택과 비동기 삭제 후보 미리보기를 제공합니다. 자동 삭제 기본값은 꺼짐이며 설정 저장은 `/api/storage/policy`로 요청합니다. 완료된 정리에서 실제 삭제가 있으면 파일 트리를 갱신합니다. 입력 중인 설정을 상태 조회가 덮어쓰지 않습니다. 삭제 기준과 동시 작업 보호는 [저장 공간 문서](../../../docs/storage_retention.ko.md)를 참고하세요.
