# 데이터 조회 화면

`controller.js`는 데이터 종류에 따라 호가·과거 1분봉·펀딩비율의 단일 소스 조회를 담당합니다. 거래소·종목 목록과 저장 범위는 `shared/source-controls.js`, 파일 구간 진입은 `shell/workspace.js`에서 연결합니다.

조회는 `/api/analyses`에 소스 종류와 수식 `A`를 전달하고 서버가 파일 읽기·집계·CSV를 처리합니다. 펀딩 소스는 `data_type: "funding"`, 단위 `%`로 요청하며 이미 퍼센트인 `values`를 다시 변환하지 않습니다. 표에는 원본 비율과 관측/서버 시각·당시 정산 잔여초를 함께 표시합니다. 평균 모드의 메타데이터는 구간 마지막 관측 기준입니다.

펀딩 차트는 `TimeChart`의 `isolatedPoints`를 사용합니다. 조회 간격보다 갱신 주기가 길어 연결할 선이 없는 관측도 점으로 표시하며, 빈 구간을 채우지 않습니다.

종류·종목·기간·조회 방식이 바뀌면 결과와 CSV를 비우고 이전 응답을 배제합니다. 파일에서 진입할 때는 지정된 종류·종목·기간을 유지합니다. 호가의 원본/평균 CSV 생성 패널과 모든 종류의 조회 결과 CSV는 별도 기능이며, 펀딩·분봉은 조회 결과 CSV를 사용합니다.
