# 백테스트

이 폴더는 과거 호가로 전략을 재생하고 손익을 계산하는 부분입니다.

- `engine.py`: 실행 조건 검증, 이동평균 교차·단순 보유 전략, 가상 체결, 수수료·슬리피지, 자산 곡선과 성과 지표.
- `__init__.py`: 외부에서 사용할 `run_backtest` 진입점.

완료된 이전 구간의 신호를 다음 호가 구간에서 실행합니다. 원천 데이터와 가격 시계열은 `../market_data/`와 `../analysis/`에서 가져옵니다. 새 과거 전략과 체결 가정은 여기에 추가하며, 진행 중인 모의 계좌는 `../paper_trading/`에서 관리합니다.

각 체결에는 당시의 누적 실현손익, 체결 후 보유량·원가, 시장가 미실현손익, 총손익·평가액과 평가 근거를 기록합니다. 매도 전량 청산 후 미실현손익은 0입니다. 내부 `run_backtest(..., theory_provider=...)`는 시각·거래소·종목을 인자로 받는 이론가 공급 함수를 지원하며 `price`, `available_at_ms`, `basis`를 반환해야 합니다. 미래 정보 또는 해당 조회 간격보다 오래된 이론가는 제외합니다. 기본 UI 백테스트에는 과거 이론가가 연결되지 않았으므로 보유분 이론가 손익은 빈 값입니다. 현재 저장된 괴리 평균을 과거 평가에 재사용하지 않습니다. 거래 CSV는 새 손익 필드와 평가 근거도 포함합니다.
