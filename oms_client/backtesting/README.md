# 백테스트

이 폴더는 과거 호가로 전략을 재생하고 손익을 계산하는 부분입니다.

- `engine.py`: 실행 조건 검증, 이동평균 교차·단순 보유 전략, 가상 체결, 수수료·슬리피지, 자산 곡선과 성과 지표.
- `__init__.py`: 외부에서 사용할 `run_backtest` 진입점.

완료된 이전 구간의 신호를 다음 호가 구간에서 실행합니다. 원천 데이터와 가격 시계열은 `../market_data/`와 `../analysis/`에서 가져옵니다. 새 과거 전략과 체결 가정은 여기에 추가하며, 진행 중인 모의 계좌는 `../paper_trading/`에서 관리합니다.
