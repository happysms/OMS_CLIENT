# 모의투자

이 폴더는 서버의 공개 시세로 가상 주문을 체결하고 모의 계좌를 유지하는 부분입니다.

- `service.py`의 `PublicQuoteProvider`: 종목별 공개 호가 구독과 신선한 시세 조회.
- `service.py`의 `PaperTradingService`: 가상 현금·포지션·주문 내역, 수수료·슬리피지, 중복 주문 방지와 계좌 초기화.
- `__init__.py`: 외부에서 사용할 서비스 진입점.
- `reporting.py`: 현물 가중평균 원가를 기준으로 시장가·이론가 평가와 계좌 전체 손익을 계산하는 순수 함수.
- `theory.py`: 실시간 빗썸 종목의 이론가 공급 모듈. OKX 중간가 × 빗썸 USDT 중간가 × (1 + 저장된 7일 관측 평균 괴리율/100)을 사용하며 과거 재생에 사용하지 않습니다.

시세 연결은 `../market_data/quotes.py`, SQLite 연결은 `../storage/state.py`를 사용합니다. 실제 계좌 인증이나 실주문 호출은 포함하지 않습니다. 향후 OMS 연결은 별도 `../oms/`의 책임이며 모의 원장과 구분합니다.

체결마다 `paper_fill_reports`에 체결 원본, 체결 전 현금·보유량·평균 원가, 체결 후 계좌와 모든 보유 포지션, 시장 호가·이론가 입력 및 시각을 JSON으로 고정 저장합니다. 계좌 갱신·주문 기록·손익 기록은 같은 SQLite 트랜잭션으로 커밋합니다. 재요청은 같은 체결 보고서를 반환하며 다시 기록하지 않습니다. 현재 시장가 모의 주문은 주문 1건당 체결 1건입니다. 자동 MM 지정가 주문·부분체결 엔진은 아직 이 서비스에 연결되지 않았습니다.

실현손익은 매도대금−매도 수수료−매도 수량의 원가입니다. 매수 수수료는 가중평균 원가에 포함하므로 총손익에서 다시 빼지 않습니다. 시장가 미실현은 수량×(최우선 매수호가−평균 원가), 이론가 미실현은 수량×(이론가−평균 원가)입니다. 두 평가를 더하지 않고 각각 실현손익과 합산해 시장가 총손익·이론가 총손익을 표시합니다. 예상 청산 수수료는 아직 차감하지 않습니다.

기준값이 없는 보유 포지션은 null로 기록하고 계좌 전체 평가도 null로 남깁니다. 잔고가 없는 포지션의 미실현손익은 0입니다. 미래 수신 시각·오래된 평가값을 사용하지 않습니다. 이론가의 평균 괴리율·기간 종료·표본 수·충족률·OKX/USDT 기준 호가도 기록합니다. 7일 충족률이 100% 미만이면 관측된 부분 구간의 평균이라는 사실이 보고서에 남습니다. `theory_provider.get_many(pairs)` 주입으로 전략별 이론가를 공급할 수 있으며 각 값에 `price`, `available_at_ms`, `basis`를 제공합니다.

`snapshot()`은 현재 평가와 최근 100개 체결 보고서를 반환합니다. `fills(before=sequence,limit=100)`은 같은 밀리초의 체결도 누락 없이 순번으로 페이지를 넘깁니다. `/api/paper/fills/csv`는 전체 기록과 평가 근거 JSON을 내보냅니다. 이전 버전 체결은 알려진 거래값만 보존하고 `legacy_unavailable`로 표시하며 현재 시세로 과거 손익을 생성하지 않습니다. 기존 명시적 계좌 초기화 기능은 포지션·주문·체결 보고서를 함께 삭제합니다. 서버 재시작은 기록을 유지합니다.

## KRW / USDT 보고 통화

`currency.py`의 `FxQuote`·`UsdtLedger`가 체결 당시 빗썸 USDT 중간가에 따른 별도 가중 원가를 관리한다. KRW 결제 원장을 유지하면서 `usdt.account`, `usdt.positions`, 체결 `usdt.fill.fx`를 추가한다. 실시간 상태 `paper_usdt_state`와 체결 보고서는 KRW 정산과 같은 트랜잭션에 저장한다. 환율 결측은 null이며 오늘 환율로 과거 원가를 복원하지 않는다. `fx_provider`를 선택적으로 주입할 수 있고 기본값은 공개 실행 시세 공급자다. [환율 계산·저장 계약·미결정 쿼리](../../docs/pnl_currency.ko.md)를 참고한다.
